# Background music — Aaj Se Teri (Padman karaoke)

Place your karaoke file here with this exact name:

```text
aaj-se-teri-karaoke.mp3
```

Full path:

```text
public/assets/audio/aaj-se-teri-karaoke.mp3
```

Then refresh the site. Click **Begin Our Celebration** to start the song (browsers block autoplay until you interact).
